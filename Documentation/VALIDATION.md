# v0.2.0 验证记录

验证日期：2026-10-03。编辑器 Unity 2021.3.16f1c1，Windows x64 / Mono / Direct3D 11。本机渲染设备 NVIDIA GeForce RTX 3080。

## 已完成验证

- Windows 构建成功，0 错误。唯一警告是项目没有绑定 Unity Cloud；离线单机功能不依赖该服务。
- 构建时逻辑校验通过：0–3 级钓具控线策略、250 个种子的商店库存去重、属性上限、精英奖励、保存往返、损坏备份恢复和失败清档。日志中的 1,715 是含逐帧循环的断言次数，不是独立测试用例数。
- 完整集成回归通过：252 次检查，包括岛面与码头行走、柜台碰撞、暂停、拒绝陆地抛竿、断线重试、实体鱼出水、真实摄像机射线命中、拿取/抛出/装篓、普通击杀不直接发钱、鱼市按估价出售、余额不足拒购、付费随机强化和防重复购买、保存/恢复、九段主线、克拉肯、幽海白鲸，以及死亡清档。
- 对首领伤害、延迟范围攻击和冲刺保护单独关闭通关保护进行检查；三个主线首领均通过。
- 完整回归之后仅调整提示背景、双面路牌、水面/天空表现与视觉采样步骤。最终构建再次通过 22 次交互/渲染检查，包括两个海域几何切换；没有再改经济或战斗规则。
- Unity 工程完整性扫描 187 个文件通过：缺失/孤立 `.meta`、GUID 重复、合并冲突、包清单和编辑器版本均无错误、无警告。
- 使用最终 Windows Player 导出并目视检查港口、村落、码头、控线、空中鱼、手持鱼、鱼篓、商店、三片海域与克拉肯画面。完整回归还导出了三个守关首领、白鲸和结算画面。

原始结果在 [TestResults](TestResults)；实际渲染截图在 [Images](Images)。数值与模拟假设见 [BALANCE.md](BALANCE.md)。

## 范围与限制

测试使用独立临时存档，通关阶段用自动瞄准与受控无敌验证流程可达性；鱼篓、金币与购买走实际游戏逻辑。白鲸分支通过设置稀有信号的测试夹具覆盖，不把随机出现率当作测试保证。

截图来自 Unity Camera.Render + RenderTexture，并包含实际场景和 Canvas，不是概念图。没有宣称已完成真人全流程键鼠试玩、长期难度研究或所有硬件的性能认证。流程、支付和持久化已验证，操作手感与最终难度仍需玩家反馈。

当前不支持自由驾驶或多人联网，岛屿交易村落使用共同布局。场景中未收纳的鱼获不保存；正常退出时会尝试把手持鱼放进鱼篓，鱼篓满时请先出售。

## 复现

```powershell
./Tools/build.ps1
./Tools/smoke.ps1
./Tools/smoke.ps1 -Visual
python -X utf8 Tools/balance_audit.py
./Tools/package.ps1
```

集成测试输出到 `Builds/Artifacts/IslandQA`，会覆盖该目录同名结果与截图；正式游戏存档不受影响。完整回归和最后一次视觉回归分别存放为 `island-campaign-results.txt` 与 `island-visual-results.txt`。
