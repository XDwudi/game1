# HOW TO FISH 参考研究与 v0.2 改版

研究日期：2026-10-03。参考来源为开发者发布的 [How to Fish / 渔力全开 Steam 商店页](https://store.steampowered.com/app/4001890/How_to_Fish/) 及其中的官方实机动图与截图。本次浏览实际查看了岸边抛竿收线、岸上击杀、物品拿取/投掷、室内道具桌和室外锻造工坊的片段；没有声称购买并完整游玩原版。

## 核心观察与落实

| 参考中的可见要素 | v0.2 实现 |
| --- | --- |
| 第一人称在岛岸钓鱼，角色能移动 | 有碰撞、重力、跳跃和冲刺的海岛；码头、沙滩、后山与交易村落 |
| 物理钓鱼与离水的鱼 | 抛竿弧线、浮漂、动态鱼线、控线张力、鱼跃出水面并落地扑咬 |
| 鱼能被击杀和操作，形成钓猎结合 | 射线枪战、实体尸体、E 拿取、Q 投掷、F 装篓、Tab 查看鱼获 |
| 卖鱼赚钱，然后购置装备 | 必须把普通鱼带回鱼市售卖；枪械、钓具、护甲、治疗和随机配件都用金币购买 |
| 不同鱼、稀有变体与首领 | 普通/精英、巨型/金鳞、三个守关首领与克拉肯、幽海白鲸 |
| 任务与区域推进 | 三海域九段委托；航图选路影响收益、精英比例与稀有信号 |

初版固定甲板上的波次射击不能充分承载上述循环，因此 v0.2 重新制作了环境、移动、实体鱼获和经济，不再沿用击杀即发普通鱼金币、免费领取三选一强化的规则。

## 自己的设计取舍

用户要求单人、3D、射击和 roguelike。由此保留单人离线远征、失败重开、局内随机商店配件，以及明确预警和两阶段的 BOSS 战。沿用钓鱼—击杀—售卖—购买的玩法方向，未复制参考游戏的角色、模型、音频、UI、地图或源码。

当前是原创建模的低多边形海岛钓猎雏形。船只用于港口环境与航路叙事，换区通过航图完成；尚无自由驾驶、多人联机、赌场小游戏、复杂 NPC 任务链或大量手工制作岛屿。这些不是本次已完成的功能，也不以“复刻原版完成品”描述此版本。
