# v0.6 验收记录与边界

## 可重复运行

先运行 `Tools/build.ps1`，再单独运行 `Tools/test_v06.ps1 -Mode Systems|World|Combat|Campaign|All -Speed 2`。只有根代理启动 Unity 和游戏；子代理编辑、审查并报告结果。v0.6 不会自动执行旧 v0.5 整套测试。

每次运行保留 `Builds/Artifacts/V06QA/<时间戳>-<模式>/` 下的：

- `build-identity.json`：可执行文件与 Assembly-CSharp 的 SHA256、模式、时间倍率、UTC 时间。
- `results.txt`：包括失败的原始断言，失败不覆盖成通过。
- `ecology.csv`：36 个实际运行时鱼池的原生比例和任意岛对最大重合比例。
- `world.csv`：逐路径点的玩家坐标、地面高度、用时、实际位移与是否到达。
- `combat.csv`：物种、精英标志、武器等级、种子、总用时、是否等待观察、第一枪前延迟、首只敌人在第一枪后存活用时、开火次数、出招/地域技能次数、伤害与结局。
- `campaign.csv`：实际钓鱼探索流程的金币、生命、任务状态、步行距离和开火次数。
- 截图：世界航拍与目的地、失败位置、战斗、精英装置、专研商店与真实流程。

本轮发布证据另存于 [TestResults/v06](TestResults/v06/)，包括各轮原始断言、CSV 与构建身份；最终完整验收见 [final-all/results.txt](TestResults/v06/final-all/results.txt)。这里的测试数量按不同测试套件分别记录，不将模型断言或画面检查累加成真实战斗场次。

## 测试分层

**Systems** 中金币和标本数据、研究等级与特定战斗条件使用明确的隔离场景夹具。它验证条件、来源、持久化和真实消费者，不证明玩家自然赚到了这些金币。水母与海马使用可见标注的固定随机物种选择，随后经过正常 Cast、TickFishing、LaunchToward、空中阶段、落地、瞄准和 Fire；不会直接把鱼挪上岸或直接扣装置生命。

**World** 可以预先开放岛屿，以逐岛检查几何。从实际出生点开始，使用 `SeaWorld.NavigationRoute` 的每一个路点和真实 CharacterController 步行；中间容差 0.5 米，末端通常 2.2 米，六个地点往返并额外连接两个任务点。逐帧检测落水与异常位移，卡住保存原坐标和截图。航拍只在路径走完后临时移动相机，不用于让角色跨过障碍。

**Combat** 的基础武器和三级改装配对是预先配置的有限装备场景。基础普通鱼和精英蟹立即开火，观察实际输出；九个地域精英为了验证招式会先等待至少两次出招，沉船修复机制会先正常射击到生命阈值。这些等待观察的总时长不能当作自然遭遇 TTK。脚本拥有有限生命与披露的医疗包，不在交战中加金币、改敌人生命或给予永久无敌。敌人有共生装置或再生蜕皮时，测试通过真实射击优先处理装置。

**Campaign** 是新远征的五次自然钓鱼路线：西岸两次、东岸两次、水道一次。没有生命、装备、金币、任务状态赠予；正常战斗、步行拾取、市场出售、必要时用赚到的钱购买鱼汤，再用 UI 按钮购买 55 金币专研并保存重载。若预算不足只增加一次正常钓鱼；死亡、卡路、拿不到鱼或付不起升级都真实报失败。

已执行的单模式结果不能替代其余模式。自动瞄准知道弱点和规则，也不能替代新玩家可读性、真实手柄/鼠标手感或长期乐趣评估。完成本轮功能验收仍不等于完成商业发行认证。
