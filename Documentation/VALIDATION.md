验证日期：2026-10-04。Unity 2021.3.16f1c1，Windows x64 / Mono / Direct3D 11，本机 NVIDIA GeForce RTX 3080。

## 已完成验证

- Windows 构建成功，0 编译/构建错误。唯一构建警告是未绑定 Unity Cloud；单机功能不依赖云服务。
- 构建时 6,731 次断言通过：119 条物种身份、九岛各 12 种普通生物可被抽取、基础拟饵门槛、商品开放条件、钓鱼策略、库存去重、属性上限、存档读写与损坏备份恢复。数字包含种子和逐帧循环，不代表独立用例数。
- 完整 Windows Player 主回归 **682 项检查通过**，用时 774.4 秒。包含九岛研究、遗迹守卫、九位首领与第二阶段、潮核交付解锁、返回旧岛、隐藏机关、终章、克拉肯、白鲸，以及死亡清档。
- 九岛均用真实 CharacterController 行走到向导和两处主线遗迹。该测试发现并修正了盐沙岛工坊挡路的问题；建筑位置与随机杂物现在避开任务路径。通关战斗测试的定位仍使用受控传送，步行检查单独执行。
- 六把武器逐一检查扣弹、三连发次数、切枪取消装填但不补弹、重新装填、连续火力散布及恢复。十四种攻击逻辑都在 Player 中执行；另测射线预警倒计时、实际伤害、冲刺免伤、毒池异常状态和最后一只易爆怪的延迟爆炸。
- 专门验证持续高频失衡伤害不能永久阻止首领出招。十二种基础体型逐一验证正面弱点可被真实 Physics.Raycast 命中。119 种生物的造型与碰撞体全部实际实例化。
- 急救、库存耗尽拒绝再次治疗、声呐与加速消耗分别验证。实体鱼获拾取、抛出、装篓、售价与金币扣除走真实游戏逻辑。
- 主回归后仅修正旧版鱼获身份迁移、尸体尺寸保持与声呐提示。最终构建又通过 **33 项交互/兼容/视觉检查**，包含旧版装备金币与鱼获保留、真实捕鱼/射击/售卖、金币升级、商店拒购及九岛几何切换。
- Unity CLI 工程完整性扫描 **203 个文件**通过：缺失/孤立 meta、重复 GUID、冲突标记、包清单、编辑器版本均无错误或警告。
- 数值审计运行 10,000 个种子；数据读取 Unity 导出的实际物种表。108 个普通物种的体型/攻击/特性组合互不重复，精英和金鳞不计作独立物种。
- 实际摄像机截图已目视检查九岛、首领、鱼获、商店、故事日志、航图和图鉴。最终 Player 退出后有一次 Unity 原生 `Curl error 42: Callback aborted`，发生在通过标记之后；测试中无脚本异常或失败断言。

## 实际覆盖与限制

通关自动驾驶使用自动瞄准和受控无敌，目的是检验流程可达、支付、碰撞、解锁与保存；伤害和闪避用独立夹具关闭保护后测试。部分购买/稀有条件与攻击压力检查采用明确测试夹具，不把随机概率或玩家技巧当成保证。

没有声称进行过真人完整键鼠试玩、长期难度调研或多配置性能认证。682 项检查不能证明所有攻击组合在所有地形都完美平衡。枪械反馈和难度已实现并作初始校准，实际好玩程度仍需要真实玩家体验反馈。

119 条物种记录使用 12 套普通身体结构与比例、附肢、颜色变化，以及独立的克拉肯和白鲸造型；不是 119 套完全独立手工模型。九岛有不同地形、地标和故事，但保留共用交易设施与研究流程。

截图由 Unity Camera.Render + RenderTexture 输出，包含运行时场景和 Canvas，不是概念设计图。测试写入隔离临时存档，正式玩家存档未被修改。
