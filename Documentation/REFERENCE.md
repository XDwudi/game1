# HOW TO FISH 参考与 v0.4 设计回应

参考范围是此前查阅的开发者 [How to Fish / 渔力全开 Steam 商店页](https://store.steampowered.com/app/4001890/How_to_Fish/) 与 [官方更新公告](https://steamcommunity.com/app/4001890/allnews/)，以及官方商店展示的岸边抛竿、岸上战斗、拿取投掷、道具桌和工坊。没有购买并完整游玩原版，也不把本项目的数值、机关或故事说成原版规则。

官方介绍提供的核心参考是物理钓鱼、鱼与武器结合、售卖与购买，以及任务和首领推动新岛。我们的设计判断是：新工具应改变选择，新目标应改变行动，进入下一岛应该获得新的问题。v0.4 针对用户指出的武器碾压、任务重复、首领同质与剧情空洞，重新组织这些关系；下表中的实现属于本项目原创设计。

| 参考方向 | 本版具体实现 |
| --- | --- |
| 鱼获售卖驱动装备成长 | 保留物理鱼获，普通击杀不自动发钱；所有升级仍用金币购买 |
| 任务推动新区域 | 从修灯守护，依次引入声音回应、净水舟护送、星盘推理、黑匣守护、热芯救援、限时送电、熔炉调控和最终封锚；调查、首领与潮核交付开放下一航路 |
| 新工具带来新发现 | 四档拟饵在每座岛分别开放 6 / 9 / 11 / 12 种生物，后期可以回访旧岛 |
| 首领与新装备逐步引入 | 九岛逐步开放枪械、配件、补给与改装；第 2 / 5 / 8 岛开放三幕金币专精，每幕三选一，形成跨幕组合 |
| 图鉴形成长期收集目标 | 119 条独立身份记录、3D 标本、攻击反制、栖息地与拟饵线索 |
| 区域变化 | 九套生态与地标保留，每岛同时改变调查规则、关键人物、证据和进入首领战的原因 |
| 战斗支持成长 | 减少无条件伤害叠乘；枪械分工、精准装填、闪避与弱点专精提供操作收益；首领阶段机关与连招要求在防守和输出之间切换 |

原创故事围绕失踪渔船、重复的一天，以及一台不愿接受失去的引潮机展开。前半程逐步找到求救录音与机器证据，中段通过实际救援改变人物处境，后半程面对关闭循环与保留记忆的选择。NPC 不只说明世界设定，也会对玩家亲手完成的事情作出回应。

演出使用当前 Unity 场景与角色：开航、九岛入场、黑匣反转、工程师自白、结局和两只传奇巨物现身，共 15 段实机过场。可通过 Space / Esc 跳过，采用中文字幕、信件叠字、镜头移动和角色关节动作，没有把它们称作离线电影 CG，也没有使用原版素材或剧情。剧情界面保留任务与证据文字；声音谜题有文字与形状提示。

Roguelike 部分来自用户要求：失败清除本局资源，图鉴长期保留；每岛随机配件与三幕专精都用金币购买。专精奖励连续弱点命中、冲刺进攻、精准闪避、低血量冒险、远距射击或元素组合，购买机会不能全部占有。路线仍在收益、精英压力与初访补给之间取舍。主线委托不设置必须购买某把枪才能推进的硬性消费门槛，可以继续捕鱼筹资。

119 条记录包括 108 种普通生物、9 个主线首领和 2 个稀有首领。精英、巨型、金鳞不重复计数。普通生物仍基于 12 类身体结构、14 种攻击逻辑和附加特性组合，并非 108 套独立动作。v0.4 增加 12 类精英战术与反制要求；同体型精英会共享战术，未宣称每一个命名物种都有独立精英脚本。

11 个首领分别编排三组招式，并在阶段转换时引入岸上可破坏机关、受保护本体与输出窗口。核心暴露期间仍可能反扑，玩家需要在额外伤害和安全位置之间选择。克拉肯强调触腕、墨涡与潮环交替，白鲸强调潜航、破冰猎线与多拍鲸歌。各首领共享阶段和机关基础设施；独特性来自招式时序、场地压力与反制组合，而非完全不同的底层系统。持续验证应同时检查无敌状态、阶段跳过、预警可读性和真实玩家承压，不能仅以自动射击通关证明好玩。

首领美术继续使用基础解剖结构，但增加 11 套专属轮廓：船舵蟹冠、珊瑚角、毒根与毒囊、背负日轮神庙、沉钟铁箍、冰冠长牙、电容天线、分节尾熔炉背甲、镜片星环、克拉肯巨眼腕印和白鲸声呐冰脊。装饰通过独立关节摆动、环绕或脉动，区分首领和普通物种；这些几何不是额外伤害碰撞体，原有正面弱点仍是有效瞄准目标。轮廓和遮挡应在实际战斗机位验证，不能只在图鉴展示中确认。

本文件记录参考边界与已编写的设计内容，不充当测试通过报告。是否编译、流程是否通过、发现了哪些问题，以本次构建的验证记录为准。项目仍是原创低多边形单人开发版本；自动流程、数值审查和画面检查不能替代持续的真人试玩与商业成品验收。
