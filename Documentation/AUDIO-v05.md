# Tidebreak v0.5 · 音乐职责交付

本轮音轨全部由本项目原创的程序作曲、加法 / 模态合成和滤波噪声生成，不含采样库、商业歌曲、外部录音或模仿指定作曲家的旋律。它们是可替换的原创开发版音乐，不能以合成程序或波形检查代替真人听感评价。

## 实际交付

- 三幕探索音乐：港湾的明亮吹管与拨弦；中段调查的木琴、刷奏和较暗和声；末段镜海的钟音、低音与更紧张的节奏。
- 普通交战、首领、传奇战斗各有独立编曲，不再仅把同一首音乐加速。首领与传奇另有同拍打击乐轨，根据第一 / 二 / 三阶段从 38% / 68% / 100% 强度逐渐进入。
- 六种枪械各有不同的瞬态、主体和机械尾音：左轮的短金属报告、散弹的低频宽响与泵动、鱼叉的弹簧 / 缆索共鸣、卡宾的短促干响、点射枪的较低枪声与枪机、雷弧枪的稳定电气谐波。取消高频向负频率扫动的旧效果。
- 33 条动作 / 反馈音、一个立体声海浪环境循环。低血量心跳和警示独立于枪声的有界声部池；声呐与机制音符保留原始音高，不做随机变调。
- 音乐、音效、环境各响应已有音量设置，主音量仍由 `AudioListener.volume` 控制。

## 混音实现

`SeaAudio` 使用两组音乐 / 打击乐源，以同一个 DSP 时间启动同拍素材。切换时进行 1.6 秒等功率交叉淡化。音乐播放速度保持 1，不再用 pitch 改变战斗节奏。同步调度使用 Unity 2021.3 的 [AudioSource.PlayScheduled](https://docs.unity3d.com/2021.3/Documentation/ScriptReference/AudioSource.PlayScheduled.html)。

对白 / 实机过场把背景降至 22%；音鳐和拉钟机制期间背景降至 35%；具体音贝音符再短暂降至 20%。降低的是背景，不改正确答案的音高，也不额外播放只对正确答案有利的提示。危险提示通过单独优先音源呈现，避免密集枪声把它们完全占掉。

普通动作使用 12 个循环复用的音源，爆发时替换最旧的声部，防止射击与命中音无限叠加。轻微音色随机由独立 `System.Random` 控制，不污染战斗的随机数序列。运行时不合成音乐或创建新声音片段；仅缺失资源时才创建安静的诊断占位音，验收必须确认 `MissingImportedCueCount == 0`。

新 API：

- `DuckMusic(seconds, amount)`：短时压低背景。
- `PlayMechanismTone(AudioClip, volume)`：保留音符音高，应用音效设置并压低背景。
- `CurrentTheme`、`MusicDuck`、`PercussionIntensity`、`LoadedCueCount`、`LoadedThemeCount`、`MissingImportedCueCount`：供验证读取，不改变玩法状态。

现有 `Init()`、`Cue(string)`、`SetCombat(bool)` 保持兼容。点射枪应调用 `Cue("burst")`；净化 / 蒸汽机关可使用 `Cue("steam")`。

## 资源导入与客观检查

42 个 WAV 源资源，32 kHz、16-bit、双声道；总计 45,717,516 字节（43.6 MiB），最大单文件约 6.51 MiB。长音乐 / 环境通过 `AudioImportSettings` 导入为 Streaming / Vorbis quality 0.72；短动作音使用 DecompressOnLoad / Vorbis quality 0.82。未手写 `.meta`，由 Unity 正常导入生成。

客观审计输出为 `Artifacts/audio-v05-audit.json`，包含每个文件的长度、BPM、峰值、RMS、直流偏移、循环接缝、削波数和六枪频谱概况。

- 所有源文件削波样本数：**0**。
- 最大源峰值：**−2.158 dBFS**，保留混音余量。
- 六条音乐主体 RMS：**−17.721 dBFS**；打击乐独立轨更低。
- 九条循环（六主题、两个打击乐层、环境）PCM 首尾采样差：**0**。
- 首领及传奇的主题与打击乐长度逐采样一致。
- 循环保留跨边界的乐音 / 混响尾巴，只对边界附近 6 ms 做连续性修正；没有每隔半分钟整首淡至静音的循环缝。

Unity 导入与 Windows 构建已成功；运行时检查实际加载 33 条效果音、8 条音乐与打击乐轨，缺失资源回退为 0，对白背景降音通过。完整战斗回归执行了普通战、首领和传奇场景切换。

这些是资源与运行状态证据，不能证明所有声卡输出或真人听感。机制音符辨认、密集交火下危险提示可听度、音量设置的主观适配，以及长时间游玩的疲劳感仍需要听音试玩验证。
