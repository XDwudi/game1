# v0.6 视觉与界面验收

本轮延续深海墨蓝、旧黄铜、浅纸色的航海仪器风格。提示以玩家下一步行动为中心，屏幕中部留给怪物、枪口和地面攻击范围。以下记录实现范围；实际截图验收由集成构建补充，不把源代码检查等同于视觉验收。

## 已实现

- 首领生命条从 90 px 缩为 75 px；原来横跨上半屏的动作面板改为右上 396 px 卡片。左侧不再重复播放首领攻略；反制说明、数值和下一步操作分别固定在行动卡、仪表和底部按键提示。
- 战斗中隐藏探索键盘说明。临时危险带压缩为 43 px，倒计时进入最后 0.65 秒会有轻微亮度变化。镜头中央不会铺满红色受击蒙版。
- 受击方向使用短弧，屏幕细红边提供通用确认；普通命中、弱点命中、击破、装甲各有不同的 X 标记颜色、数字及停留时间。无来源伤害不显示猜测方向。
- 精英存在时，右侧显示其反制方法和蓄势进度。准星目标条只承担身份、专属标记及生命显示，避免把长篇招式说明叠到目标身体上。
- 工坊六页保持原有五页索引，新增「岛屿专研」。九岛选择、当前/下一阶效果、两种专属标本、金币和解锁门槛分开显示。普通商店第三行收紧到返回按钮上方。
- 生物图鉴标注专研标本与本航次研究状态。不同拟饵的鱼池包含 78.6%–85.7% 原生种，不把变色当作新物种。
- 新的共享顶点造型替换鳐盘、龟壳、水母伞、乌贼胴体、蟹甲等标准球体；背腹分色、背脊明暗和局部笔触在网格顶点中实现。蟹甲具有甲缝与边齿，龟壳有盾片缝，水母有辐射神经和伞缘，乌贼有侧鳍，鳗有背鳍。
- 鱼体不再把眼睛、鳍和全部身体一起乘同一种颜色。鳍的膜、鳍条及前缘分层，精英通过黄铜色珊瑚冠形成远处也可辨认的轮廓。盐晶、冰晶、火山和镜鳞装饰改为有棱面的薄片，保留各岛既有生态身份。

## 接口

`SeaHUD.DamageFlash()` 保留；`DamageFlash(Vector3 source)` 使用真实伤害来源显示方位。

`SeaHUD.HitMarker(bool critical, float damage, bool killed = false)` 与旧两参数调用兼容。

`SeaHUD.ShowIslandMastery()` 打开当前岛专研。商店购买仍走 `GameDirector.Buy` 和 `ShopCatalog.Lock`，UI 不直接发放能力或标本。

所有模型新增内容均不增加战斗碰撞体，原命中体、弱点和招式逻辑保持各自的责任边界。该说明不意味着新外观不需要实际射线测试。

## 必须实际拍摄并验收的镜头

1. 白天松风港朝向码头：探索 HUD、任务点、钓场线索和武器都可读。
2. 珊瑚、霜雪、熔岩三个岛：同类生物的背腹色、鳍条、岛屿附件都可辨认；高亮环境不淹没弱点。
3. 精英乌贼、精英鳐和精英蟹：侧栏及时显示反制，核心战场不被长文字遮住。
4. 普通命中、弱点、击杀以及来自左/右/背面的伤害：X 和受击弧方向正确，静止画面之外也需检查短时反馈。
5. 克拉肯第三阶段红潮：行动卡、金色换侧圈、脚下预警和鱼竿同时看得清；不要把动作卡做成全屏横幅。
6. 白鲸第三阶段真/假回波：留空后的上半屏不遮住观测目标，双段破冰说明仍完整。
7. 工坊枪械页第三行及全部九岛专研页：无按钮重叠、价格与锁定状态正确，标本不足不得购买。
8. 1600×900 和 1280×720：商店、图鉴、字幕和普通战斗不存在裁切或文字覆盖按钮。

## 首轮画面审查

已实际查看 `V06QA/20261004-160149-Systems` 中的 `research-workshop-unlocked.png` 与 `natural-elite-5-anchor.png`。工坊的九岛选择、专研内容、标本与返回按钮无可见遮挡；精英侧栏文本可读，枪械倒角在游戏镜头中可见。

审查发现共生灯的满亮青色球严重占据视野。因此将它改成受黄铜保护肋包围的小晶核与海洋灯笼，使用独立低自发光材质；保持原射击体积、生命和交互规则。此项修正需要下一次构建截图验证，不能把上述旧截图当成修正后的证明。

第二轮 `V06QA/20261004-161642-All` 的实际共生灯截图已确认晶核与护架清楚，不再出现整颗满亮青球。九岛航拍显示不同地形与桥路，近地截图确认探索文字和道路可读；雷暴岛夜景保留可辨的地面和任务设施。航拍发现的海底网格边缘深浅接缝已在着色器中修正深度换算，最终构建仍需重新看图确认。

## 最终构建画面检查

程序集 `DBCE8EBFA734FE4EFF000600D469E77E8AEA3A19507D526286C321FD19FAD66A` 的 ArtReview 为 **135 PASS / 0 FAIL**。1600×900 和 1280×720 的地面圈、向内箭头、计时弧、左侧受击弧与弱点确认均实际拍摄；主代理逐图检查了完整范围、受击方向和装填条的可读性。枪械使用真实 Fire/Reload 生成画面，命中数字使用明确标注的视觉夹具。

初次 ArtReview 的两处白鲸失败来自检查时机：它按机制下潜，测试却要求此时从码头直接射到核心。修订后通过正常声呐与走位完成观测，等待实际上浮，再执行原先的码头射线和正面弱点射线断言；两种分辨率均通过，没有删掉检查或修改首领生命、阶段。原失败保留在 `TestResults/v06/art-initial`。

最终 `164003-All` 的松风岛航拍已确认海底边界的三角深浅接缝消失。实机图片见 [海岸](Images/v06-coast.png)、[预警视觉夹具](Images/v06-warning.png)、[正常声呐后上浮的白鲸](Images/v06-whale.png)。

这台 RTX 3080 / Ryzen 9 5900X 机器上，1600×900、正常时间、单只克拉肯的 3 秒采样为 269 帧，均值 11.16 ms、P95 11.47 ms，接近 90 FPS 上限；这只是短窗口观察，不是长时间或全设备性能保证。
