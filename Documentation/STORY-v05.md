# Tidebreak v0.5 剧情与探索内容合同

本轮文本为原创。它服务已经实际操作的调查、首领机制和金币成长，不以增加说明书字数代替剧情变化。最终运行与画面验收由统一构建完成，本文件不是测试通过报告。

## 修正的叙事问题

1. **固定家庭关系**：阿澜是露珂与赛因的女儿。露珂反对用机器代替乘客选择，与赛因决裂；女儿获救并不自动让父母和好。赛因的责任不被善意动机免除。
2. **固定时间规则**：七船困在同一场风暴的重复航次。磨损、碎片证据和人物记忆残片能累积；不是船长在出生前沉船，也不是百年穿越。黑匣第八次记录证明行动已经不同。
3. **区分两种灯**：现实航灯照向岸，为真实归航提供导航；引潮回路的假灯照向海底，将船引回重播。修灯与停止循环不再互相否定。
4. **救人改变状态**：第六岛从冰封名单救出阿澜，归还船票；其后台词承认结果。主角不只是再交一份材料。
5. **结局不暗改事实**：两种记忆选择都释放乘客，不撤销救援；区别是是否携带循环里的经历。保留记忆导致终战更多回声守卫，玩家在选择界面获知。
6. **首领因果清楚**：九首领分别把某项救援/防护功能变为阻拦；当地任务先引入相应操作主题。克拉肯与白鲸属于循环解除后的自由生命，不能被解释成同一机器的另两把锁。

## 人物对话与秘密

`NarrativeContent` 提供九岛各六种状态，共54段：初见、受托、途中、首领前、胜利、复访。用 `Dialogue(run, game.MissionActive)` 和 `BeatLabel(...)` 选择。途中状态考虑运行中的任务，避免解冻等未设置证据位的任务没有中途台词。对话最后一页才显示原有 `AdvanceStory` 确认，翻页不写入进度。规则另存 `Instructions`，不让角色念距离与秒数。

`IslandEvidence` 有九份现场推理，每份三种独立反馈。题面本身包含全部依据，不要求背旧对话，不依赖音色识别。答错得到相应线索，可以继续尝试；不刷相同战斗作为惩罚。正确后调用原 `CompleteSite(2)`，复用探索位 `4`，无需新存档结构。

`JournalEntries(run)` 只返回已收藏内容 `{Stage, Title, Text, Payoff}`。玩家界面显示 `Title/Text`；**`Payoff` 为策划核对后续伏笔的说明，不对未到达的玩家展示**。已完成岛屿复访且收过证物时，`Dialogue` 自动附一句向导回应。既有 v0.4 已发现的秘密可读取为相应证物，避免让老存档再次做同一地点。

## 战斗文本边界

`BossNarrative` 有11份身份因果、人物战前建议、输入教学、失败后恢复提示、三阶段短句与胜利变化。数值以 `BossMechanism` / `EncounterTuning` 为准。已经按实现核对：净化和热炉为按住 E；雷母跑入接地圈自动泄放；熔甲温度25–45、压力低于65；镜鲨先在起点按 E；白鲸双环是真回波，所有回波都可能运动。最新白鲸规则为每阶段 2 / 2 / 3 次观测：正确观测点按 E 只发起确认，蓝线追踪变橙锁定后成功避开破冰才保存本次；第二阶段起没有直接给答案的方位箭头。克拉肯第二阶段起红潮会切换金色借力圈并生成锁定腕击，第三阶段多腕仍在时叠潮环；圈外收线不推进。图鉴、HUD 与过场文字不能继续只写“按 E 定位即完成”或“站原地松紧鱼线”。

人物台词可以用比喻，操作提示必须说明真实输入。持续机关不是全部“打碎物件、七秒无敌输出”：毒鳗逐步减甲、热炉高温减甲、雷母带电风险收益、镜链连通收益、克拉肯每腕减压等分别表述。

## 实机过场接入

在 `VoyageCinematicPlayer.Play` 的 `BuildSequence()` 之后，对每个现有镜头做：

```csharp
shots[i].line = NarrativeCinematicText.TextFor(sequence, i, shots[i].line, game.Run.storyChoice);
shots[i].document = NarrativeCinematicText.DocumentFor(sequence, i, shots[i].document);
```

此方法保留所有镜头、时长和摄像机恢复逻辑，替换矛盾文本：序章不提前声称完整知道第九次；黑匣不再说沉没发生在出生前；第七章明确露珂/阿澜关系，送去火山的是关闭指令；终章区分假灯与正常航灯；传说战介绍鱼竿牵腕与声呐识别 / 破冰确认；后两阶段的换侧和隐藏方位需要与最新操作教学一起核对。

文本会增加汉字集合，最终构建前须重新运行项目字体子集准备。美术负责分段分页与实际分辨率下的阅读验收；不能仅凭字符串存在宣布字幕可读。

## 场景后果与叙事边界

`IslandRestoration` 已接入世界生成：任务完成后与首领击败后，各岛重建不同的可见修复层。第六岛确实生成打开的舱体与持船票的小乘客；第九岛确实生成亮灯并向外航行的七艘小船；已发现证物在向导旁有保存副本。它复用 `questStep`、`bossCleared`、`exploredMask` 与旧岛进度，不新增独立的剧情保存条件。九岛具体模型差异见 `ART-v05.md`。

剧情中的“冰路融开”“海潮恢复”等大范围结果仍含叙事表达：实现没有替换整张地形或加入七艘可操控大船。过场是现有实机摄像机镜头配字幕，当前没有角色配音、预渲染 CG 或电影级面部表演。54段指六种进度状态 × 九岛的对话资料，不是54个支线任务，也不是已获得真人喜爱度数据。最新构建仍须核对字幕与机制同步、记忆选择前后事实连续、复访证物回应，以及读完末页才推进任务。
