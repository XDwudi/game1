## 金币购买

初始 25 金币、100 生命。普通击杀产生实体鱼获，需要收纳与售卖；首领悬赏直接到账并恢复 25 生命。首次遗物固定奖励 25 金币，潮核交付奖励为 50 + 岛屿序号 × 10。隐藏宝箱给 60 + 岛屿序号 × 10 金币、一枚声呐和古神信号。

| 商品 | 金币 | 效果 / 上限 |
| --- | ---: | --- |
| 枪械改装 | 85 + 等级 × 40 | 每级基础伤害 +18%，上限随许可证开放，最多 5 级 |
| 钓具改装 | 65 + 等级 × 40 | 更快收线、更稳张力，最多 3 级 |
| 防护背心 | 90 + 等级 × 40 | 每级生命上限 +25，并恢复 25，最多 3 级 |
| 扩容鱼篓 | 70 + 等级 × 40 | 每级 +4 容量，固定商品最多 3 级 |
| 霰弹枪 / 卡宾枪 / 鱼叉 / 三连发 / 电弧 | 150 / 230 / 300 / 360 / 480 | 本局购买后持有 |
| 甲壳 / 荧光 / 深渊拟饵 | 95 / 190 / 310 | 拓展各岛可发现物种 |
| 补偿器 / 瞄具 / 靴子 | 75 / 95 / 95 起 | 逐级 +40，最多 3 / 2 / 2 级 |
| 鱼汤 / 急救包 | 25 / 45 | 恢复 40 / 45 生命，满血不能浪费急救 |
| 震爆弹 / 冰封瓶 / 声呐 / 加速药剂 | 40 / 50 / 25 / 35 | 消耗品，不因当前库存递增价格 |
| 诱鱼粉 ×3 / 禁忌鱼饵 | 35 / 260 | 更快咬钩及提高金鳞机会 / 开放克拉肯 |
| 随机配件 | 80 / 110 / 140 | 按前三、中三、后三岛定价；每岛三个槽位各限购一次 |

普通基础售价由物种定义，第一岛 23–45，最后一岛 79–101。精英 ×1.65；巨型售价 ×1.6、生命 ×1.25；金鳞售价 ×2.6；凌空 ×1.25；弱点击杀 ×1.15；丰渔航路 ×1.15。幸运配件每件增加 15% 基础收益。

精英概率为 8% + 当前岛序号 ×1.8%，猎场额外 +18%，且全体生命 ×1.12。通常金鳞概率 4.5%，使用诱鱼粉为 10%；巨型与金鳞互斥。普通物种生命为 (36 + 本地编号 ×4) × (1 + 海域索引 ×0.2)，精英再 ×1.65。

10,000 个种子的最低研究任务模型中，全部走丰渔、售卖研究鱼、领取遗迹和主线悬赏：无技巧奖金收入中位数 **7,270**，混合技巧情形 **7,777**。不计初始 25、守卫鱼获、隐藏宝箱、额外钓鱼；未扣商品、治疗开支。模型假设使用当前已开放的最高拟饵，技巧情形假设 20% 凌空与 35% 弱点击杀。

买满全部固定装备共 5,040 金币；再买各岛随机配件需要 2,970 金币，还没计消耗品。因此主线可支撑完整的个人搭配，买齐所有内容需要额外探索。前三岛无技巧累计收入中位数约 356 / 805 / 1,396，足够依次获得新武器与拟饵，优先顺序仍影响早期体验。

## 枪械与反制

| 武器 | 基础伤害 | 弹匣 | 间隔 / 装填秒 | 理论持续 DPS |
| --- | ---: | ---: | --- | ---: |
| 左轮 | 23 | 8 | 0.34 / 1.3 | 45.77 |
| 霰弹枪 | 11 ×7 | 5 | 0.85 / 1.8 | 63.64 |
| 鱼叉 | 100 | 3 | 0.98 / 2.1 | 59.52 |
| 卡宾枪 | 14 | 24 | 0.115 / 1.8 | 73.68 |
| 三连发 | 25 | 18 | 连发 0.11，组间 0.3 / 1.9 | 89.64 |
| 电弧枪 | 48 | 8 | 0.58 / 2.2 | 56.14，不计连锁 |

持续 DPS 假定命中所有弹丸并等自动装填。霰弹枪 10 米内全伤，35 米衰减至 30%，另有散布脱靶。卡宾枪持续开火会扩散，停火恢复；三连发强调短点射；电弧基础可连接两个邻近敌人，半伤并短暂打断。右键瞄准降低散布，补偿器降低镜头后坐。切枪准备 0.32 秒，各弹匣独立保存，取消装填不会加弹。

武器改装和伤害配件分别相乘；暴击基础 8%、最多 50%，暴击倍率 1.75。弱点倍率 1.65，并绕过装甲非弱点减伤。防御配件最多减伤 35%，冲刺冷却最短 1.6 秒；冲刺无敌 0.3 秒，受伤保护 0.6 秒，成功免伤也不会附带毒和减速。

首领生命从 420 每岛增加 190，最终为 1,940；克拉肯 3,100，白鲸 2,800。半血转换第二阶段，增加延迟落点和出招频率。防护状态承受 72% 伤害；失衡打开三秒暴露窗口，但首领七秒内不能再次失衡，防止无限打断。攻击反制包括横移躲射线、跳过潮环、绕开毒池、打断治疗和先处理幼体，图鉴中可查。

## 保存与平衡边界

死亡重置本局装备、金币和许可，图鉴与历史纪录保留。正常退出和通关保存远征；九岛任务与已购库存均恢复。v0.2 任务状态迁移为当前岛新调查，保留装备金币。

数值模型没有模拟真人反应、失误、地形利用或连续长时间游玩。自动通关采用受控无敌和自动瞄准检查流程；伤害、冲刺、异常状态、预警和弱点另有实机断言。当前参数是可玩的初始平衡，仍需真实玩家反馈迭代。
