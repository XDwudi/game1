# v0.6 岛屿生态与金币研究

## 玩家的下一件新事物

每次到岛先看到地域轮廓与三处不同钓场。西侧与东侧各有一只岛屿专属生物，基础海蚯蚓即可钓到。第一次击败任一专属生物得到研究蓝图，玩家仍需到工坊付金币购买能力。另一份标本开放第二级，走遍三处钓场并拿起实际鱼获开放第三级；不用重复击杀二十条相同的鱼。

每个生境第二次成功收线，会优先抽出该处尚未击败的专属生物。这个规则提供战斗机会，不会跳过战斗、赠送标本、赠送升级或直接支付奖励。探索西岸两次、东岸两次，再到湾心水道拿到一份鱼获，理论上五尾可以完成蓝图与三生境条件。玩家可能更早随机遇到它们，也可能因战败需要重试。

## 生物差异

保留旧存档物种 ID：普通生物 0–107，首领 108–118。每岛十二种原生生物，另外有三种来自前一岛的普通迁徙生物；迁徙生物不包括专属标本。所有岛均有两只仅出现在本岛的专属物种。

| 拟饵等级 | 原生种 | 迁徙种 | 原生占比 | 任意两岛最大共同占比 |
| --- | ---: | ---: | ---: | ---: |
| 海蚯蚓 | 6 | 1 | 85.7% | 14.3% |
| 甲壳拟饵 | 9 | 2 | 81.8% | 18.2% |
| 荧光拟饵 | 11 | 3 | 78.6% | 21.4% |
| 深渊拟饵 | 12 | 3 | 80.0% | 20.0% |

实际抽取先以 82% 概率选择原生子池，再优先尚未拿起记录的鱼种；其余概率进入完整池，因此原生实际权重高于 82%。固定标本机会优先于该随机步骤。不同地域通过 `EcologyStyle` 与 `ecologyMark` 向战斗和美术提供共同的数据：潮线突进、护礁横移、根须潜伏、沙纹游走、沉物伏击、冰线漂游、雷步绕行、蓄热追猎、镜像侧移。地域行为与模型装饰由对应战斗/美术模块消费，物种仍保留各自的体型、招式和属性。

迁徙种保留原生外形、名字、ID 与地域机制，但真实钓获时按当前岛的进度预算调整战斗数值。`Enemy.SetCatchOrigin` 将生命乘以 `(1 + 当前岛索引 × 0.19) / (1 + 原生岛索引 × 0.19)`；`CombatIsland` 供普通、精英与地域技能计算伤害和装置生命。基础售价改为 `25 + 当前岛索引 × 7 + 族内编号 × 2`。因此环流带到松风灯塔的镜渊生物不会偷带终章生命、伤害或卖价，松风迁徙到第二岛的生物也按第二岛预算成长；本地生物比例为 1，保持原数值。

召唤幼体通过独立的 `InheritCombatBudget` 继承亲本的遭遇岛预算，再应用幼体 35% 生命比例。此路径不会复制 NaturalHook 或钓获岛/生境：幼体仍是 Summoned/Minion，不掉鱼获、不解锁专属蓝图，也不能贡献生态奖励。重新设置同一来源按先前战斗预算计算比例，避免重复调用累乘生命。

## 九条金币研究

每条三阶，一级价格为 55 + 岛屿序号 × 8（序号从 0 起）；第二、三级各再加 40 金币。一次远征中保留，返回旧岛不重置。

| 研究 | I / II / III 级效果 | 操作条件 |
| --- | --- | --- |
| 松风追潮 | 首个弱点 +14 / 22 / 30% | 冲刺后 3 秒；5 秒冷却 |
| 珊瑚折射 | 向另一目标折射 20 / 30 / 40% 伤害 | 弱点命中，邻敌在 6 米内；2.5 秒冷却 |
| 根须萃取 | 恢复 4 / 6 / 8 生命 | 击败真实钓获；召唤物无效 |
| 日轮破势 | 蓄势弱点 +15 / 25 / 35% | 看懂并射击敌人的出招前摇；3 秒冷却 |
| 沉钟快装 | 下一枪 +10 / 18 / 26% | 完成精准装填后 5 秒内；打空也消耗 |
| 霜径回身 | 范围减速 0.55 / 0.80 / 1.05 秒 | 冲刺时 5 米内普通/精英；6 秒冷却，首领免疫 |
| 避雷蓄能 | 下一次受伤 -20 / 30 / 40% | 真实闪避挡下攻击后 5 秒；一次性护盾 |
| 熔心处决 | 残血弱点 +20 / 30 / 40% | 目标生命 ≤30%；4 秒冷却 |
| 镜渊换弦 | 换枪弱点 +10 / 16 / 22% | 有效命中后 4 秒内换另一把枪；3 秒冷却 |

松风、日轮、熔心、镜渊对同一目标同一枪的条件增伤相加，上限为 65%，不会彼此指数相乘。珊瑚折射不递归触发命中能力，也不跳过首领的机关护甲。所有效果只经真实射击、冲刺、装填与受伤路径进入。

## 六项通用选择

新增快拆弹匣（装填每级 +8%）、回正握把（散布恢复每级 +20%）、装填导轨（精准窗口两侧各 +2.5%）、卸力线轴（松线卸张力每级 +18%）、精英样本箱（真实钓获精英售价每级 +10%）、压缩救护袋（急救包恢复每级 +8）。均最多三级，基础价格依次为 55、50、60、40、65、45，逐级加 40。它们提供操作、风险与收益选择，不是无限购买基础攻击力。

原有枪械许可证、钓竿等级、随机库存和每章节三选一流派均保留。专研不消耗随机库存，蓝图也不替代金币。

## 来源与老存档

真正收线出水时赋予 `Enemy.NaturalHook`、`CaughtIsland`、`CaughtHabitat`。战利品拷贝到 `CatchData.naturalHook/caughtIsland/habitat`。生态笔记按实际钓获岛记录，而不是按鱼的原生岛推断；迁徙鱼不会把奖励错误记给上一座岛。

自然来源要求进入战斗前处于真实 Fishing 状态且收线进度达到 1。只调用 `BeginCombat(false)` 的隔离场景不能借用自然鱼获标志。

召唤鱼、剧情生成敌人、任意 `SpawnSpecies` 测试敌人默认不带来源，不得解锁蓝图。旧存档物品缺少新来源字段时仍可出售，但不补发新奖励。缺失或短数组由研究 API 安全处理；已购等级有上限。专属标本只记录一次，两份位标记随远征存档保存。

## 验证边界

`Tools/v06_ecology_audit.py` 为独立有限集合/经济模型，完成 342 项断言：36 个鱼池、任意岛对重合率、基础三生境入口、标本排他性与 27 组保守售价预算。它记录被分析源文件 SHA256，不能替代 Unity 运行时验证。

预算按每岛基础原生池的平均售价估算，不使用金鳞、巨型、精英、空中击杀、弱点击杀、幸运、航路倍率或任务奖励。依此均值，两尾售价可覆盖本岛一级专研，四尾可覆盖一级专研与 40 金币卸力线轴；这不是任意两尾的保证，例如第一岛最低价两尾合计仅 50 金币，低于一级专研的 55 金币。新远征初始的 25 金币为独立启动资金，未计入上述鱼获收益。实际购买能力取决于鱼种、成功击败并拾取出售，以及补给支出；模型未扣除补给消耗，也不代表真实新手难度或乐趣评测。

验收还应覆盖真实收线 → 地域怪物 → 击败 → 图鉴标本 → 工坊扣费 → 对应战斗效果 → 存档重载，以及迁徙鱼跨岛归属、精英奖励来源、无来源/召唤拒绝、重复击杀不重复解锁。纯模型通过不应标记这些运行时项目已完成。
