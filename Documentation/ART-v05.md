# Tidebreak v0.5 — 美术、界面与可读性

## 本轮落地

沿用低多边形海岸、风化木材、黄铜仪器与纸质航海记录的方向。界面以深海蓝为底、浅纸色正文、金色行动提示、薄荷色已完成状态。颜色之外始终给出文字、进度数字、方向箭头或形状；没有必须只凭音高或红绿色差判断的操作。

- **战斗仪表**：Boss 血条在顶部，当前机制在 130–269 的独立区域。十一种机制读取 `BossMechanism` 实时状态；温度、压力、电荷倒计时、钟拍时窗、收线进度和张力使用相应仪表。永久移除“所有 Boss 先射掉发光机关”的错误教学。
- **失败与恢复**：系统通知独立放在机制下方，不覆盖机制说明；进度条不会用计时假冒已完成状态。错误动作后的恢复原因仍可读。
- **危险应对**：HUD 读取玩家实际位置与 `ThreatField.Threatens`，显示横移、跳跃、离开光圈或向外冲刺。对正在覆盖或逼近玩家所在位置的区域威胁告警；这是范围/响应提示，不代表预测所有普通子弹的轨迹。普通落点 `DeckWarning` 保留。危险条下移，避开精准装填条。
- **世界目标**：动态投影机制目标和主线目标，提供距离、菱形或屏边箭头。白鲸第一阶段指示对应观测点，第二阶段起仅指向需要观察的海面，不泄露正确方位；确认后的行动改为等待破冰锁定并横移，不显示指向玩家脚下的箭头。第三阶段动作文字显示“折返破冰 1 / 2、2 / 2”，第二道有独立的新追踪和锁定，两道都避开才保存一次观测。靠近准星的标签抬起，保护目标轮廓与射击视线。
- **对话**：叙事按人物自然段分成短页；前后翻页，只有最后页显示接取/交付按钮。右侧操作步骤独立，不夹进人物台词。复访使用独立对话。
- **船长日志**：J 直接打开三个并列入口——航行纪事、证据收藏、生态笔记。九份证物只展示已收集内容，不展示策划内部的后续伏笔说明。证据推理显示完整依据、三个判断与可恢复的错读解释。
- **航图**：纸海图背景、低对比经纬格、虚线航路、九岛插画与停泊动作；已收藏证物的岛屿会标记，而非重复九张大功能卡。
- **探索线索**：`CoastalHabitatArt.Build(parent,island)` 在三钓场生成可识别景物。西岸礁石/贝壳、中水道水纹/双浮标、东岸浮叶/海草。浮标用一/二/三道刻记区分，草叶、浮标与鱼背有轻微动画。所有对象在海面 x=-20/0/20、z≈30，没有碰撞，不阻挡码头或战斗。
- **岛屿后果**：`IslandRestoration` 读取既有任务与岛屿存档，每 0.5 秒检查。任务完成与首领击败是两级可见变化；只生成独立动态子树，不修改旧静态地形。复访可重建结果，stage 10/11 不把传说海域误认为第九岛；状态升级通知等待安全探索与现有通知结束，首次加载不刷屏。
- **舒适性设置**：总音量、音乐、动作提示音、环境声独立滑块；65–100 视野、灵敏度、镜头震动、步行起伏和下一局难度。设置读取 CaptainLog，控制实际音频/镜头由对应系统执行。

### 声呐站近距离遮挡与截图模式

复核 `20261004-131757-Negative-118/whale-sonar-from-station-phase-1/3.png`：海面回波已是高于水面、面向视线的竖直环，第三阶段左侧双环可辨。但声呐站中心有巨大蓝灰近景遮住中央回波与视野，因此“地形射线48/48无阻挡”不足以证明玩家能辨认全部回波；这项检查没有涵盖无碰撞的机制装饰。

源码调查发现测试将船长放到声呐站中心，再朝海面看。该道具包含伸到视线高度的碟面与蓝灰支杆，会进入相机近裁剪区；第一与第三阶段均可重现相似遮挡。正常鱼叉仍位于右下，未发现武器尺寸异常的证据。截屏中模型还遮住 HUD，是 `SmokePilot.Capture` 临时改为 ScreenSpaceCamera、原平面距离0.2米所致；实际游戏 Canvas 使用 ScreenSpaceOverlay，不能把该截图现象直接写成运行时HUD层级故障。

统筹已在源码中把截图平面改为 `nearClipPlane + 0.002`，为声呐道具加入半径0.75米、高2米的局部胶囊阻挡，防止正常行走进入碟面；测试观察点改从正常可交互距离拍摄，并另查真实行走阻挡。此前牵引圈/钓线变白也已通过 `TintLine` 同时设置材质颜色与发光颜色修正。以上为已检查源码的修复，尚待新构建图片确认；没有根据旧截图先行记录为视觉通过。
