# v0.5 独立测试与证据口径

本轮目标是验证玩家行为确实发生变化，兼顾探索、金币成长、关卡任务、叙事收藏、操作、预警和存档。自动化通过不等于已经验证人类玩家的乐趣或商业成品品质。没有把脚本知解、精确瞄准视作普通新手的表现。

## 运行入口

先由主代理构建 Windows 玩家，再运行 `Tools/test_v05.ps1`。可选 `-Mode Systems`、`-Mode Negative`、`-Mode Bosses`、`-Mode Campaign`、`-Mode All`；`-Mode Coastal` 单独复测三种栖地的实际捕捞与研究奖励。首领可用 `-Boss 108` 至 `-Boss 118` 单独复现，`-Speed 1` 为真实时间，默认 2 只加快游戏时间，不增加角色每游戏秒移动速度。

每次运行使用独立时间戳目录 `Builds/Artifacts/V05QA/<run>/`，保留 `results.txt`、`combat.csv`、`phases.csv`、`build-identity.json` 和截图。二进制身份记录实际 EXE、Assembly-CSharp 的 SHA-256 与时间，避免运行过程中源码继续修改造成证据混淆。播放器日志 `Artifacts/v05-<run>.log`。失败不删除、不转成通过；修复后新跑一轮保留前后证据。

## 三类证据严格区分

1. **正式首领战**：起点前只初始化一次对应阶段已付费装备档位、生命、有限急救包。开战后使用真实 `Motor.Move`、武器 `Fire`、`Dash`、`Jump`、机制公共 `UseAction` / `SetActionHeld`；不传送、不直接减首领血、不调用私有完成方法、不注入进度、不无限药、不设无敌。行走采用玩家速度 5.2，包含鞋、减速和药剂修正，冲刺期间不叠加一份额外行走位移。只使用预设有限医疗物品和合法天赋回血。记录种子、装备、血量、受伤、药量、射击、全部三阶段、机制动作、失败数和时间。
2. **反例与机制单元契约**：射击但不执行主机制应无法过首阶段；远离机关/不持鱼竿/提前拉钟/音序错误应失败且可重试。此类单元测试允许明确标注的位置布置，不能作为正式战通关证据。
3. **系统隔离契约**：旧九岛任务和存档回归保留其原有隔离 fixture（包含任务测试传送、敌人清理及无敌）；这只证明任务状态机和存档，不证明任务战斗难度。真实钓鱼经济闭环另外通过合法钓鱼、击杀、拿鱼、卖鱼、买升级验证。栖地津贴使用带 fieldSample 的实体鱼获 fixture 隔离唯一性，不能冒充三处实钓。

另加 **Campaign 端到端**：从主菜单实际按钮创建新档，沿真实道路步行，E 打开 NPC 分段对话并点击翻页/确认；真实钓鱼、射击、走到鱼获旁拾取、走到鱼市出售；工坊根据实得金币点击商品按钮升级；步行拿电池、实弹护灯、猎潮钟启动巨蟹并以真实机制/武器取胜；步行回 NPC 点击分页交付，航图按钮前往第二岛；用合法所得购买新枪，暂停菜单保存退出、主菜单继续恢复。整段没有测试传送、金币/生命/任务/装备注入、直接伤害或无敌。这里的正确答案与预警识别仍是知解机器人。`campaign.csv` 记录沿途钱包、生命、任务、步行距离和枪数；死亡或缺路会立即把该链标记失败并拍照，不靠 fixture 跳过。

## 首轮源码审查关注点

- 机制破解前有些首领允许削血至当前阶段底线，这是有意保留的持续输出收益；关键验证为不执行机制不能跨阶段或击杀，不能把“能造成伤害”误报为绕过。
- 同一机关形式在任务和首领战重复出现时，需评估是否有新的决策压力，而非只重复劳动。热炉护送与熔炉双阀尤其需要人类试玩检验节奏。
- 提示应同时用形状、位置、文字、声音表达；截图验收必须看当时阶段的目标，不能用旧“岸上射节点”基准误判新潜航机制。
- 自动化能读 `Melody` 和 `MirrorSolution`，并对视觉预警作完美识别。这是回归驱动，不是首次遭遇的理解率测试。发行前还需陌生玩家的无指导首轮试玩。
