# HOW TO FISH 参考研究与 v0.3 改版

本次继续查阅开发者的 [How to Fish / 渔力全开 Steam 商店页](https://store.steampowered.com/app/4001890/How_to_Fish/) 和 [官方更新公告](https://steamcommunity.com/app/4001890/allnews/)，并延续 v0.2 对商店实机动图、岸边抛竿、岸上战斗、拿取投掷、道具桌与工坊的观察。没有声称购买并完整游玩原版。

官方描述强调物理钓鱼、鱼与武器的结合、售卖与购买、任务/首领推动新岛、稀有变体。近期官方公告还提到新岛、怪物、武器、NPC、拟饵和图鉴提示。我们据此提炼的是「拿到新工具后发现新生态，再用新目标推动远行」的节奏，不把非官方攻略的具体数值当成原版权威规则。

| 参考方向 | 本版具体实现 |
| --- | --- |
| 鱼获售卖驱动装备成长 | 保留物理鱼获，普通击杀不自动发钱；所有升级仍用金币购买 |
| 任务推动新区域 | 每岛向导、两类样本研究、两处调查、首领潮核交付，随后开放新航路 |
| 新工具带来新发现 | 四档拟饵在每座岛分别开放 6 / 9 / 11 / 12 种生物，后期可以回访旧岛 |
| 首领与新装备逐步引入 | 九岛许可证逐步开放六把枪、配件、消耗品和改装等级 |
| 图鉴形成长期收集目标 | 119 条独立身份记录、3D 标本、攻击反制、栖息地与拟饵线索 |
| 区域变化 | 九套岸线参数、植被、颜色、NPC 和大型地标；不同本地物种池与守关首领 |

原创新增的故事围绕归航灯、黑潮、被折叠的航线和引潮机展开。九个章节带来连续线索；隐藏符文机关提供金币和古神信号，结局后还有克拉肯、白鲸与图鉴收集。

Roguelike 部分来自用户要求：失败清除本局资源，图鉴长期保留；随机配件由金币购买，每岛限量，路线在收益、精英和初访补给之间做选择。主线没有因买错东西而彻底卡死的消费门槛，随时可以继续捕鱼。

119 条记录包括 108 种普通生物、9 个主线首领和 2 个稀有首领。精英、巨型、金鳞不重复计数。普通生物使用 12 种身体结构结合参数和附肢变化，14 种攻击逻辑与八种额外特性组合；不宣称有 108 套完全独立的模型和攻击动画。

这是原创低多边形开发版本，没有复制参考游戏素材或剧情。保留了共用交易设施和相同的核心研究节奏；尚无自由驾驶、多人联网或完整商业游戏规模的演出。验证自动流程可达，不把自动通关称为已完成真人体验测试。
